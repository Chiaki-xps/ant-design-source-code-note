# 项目初始化

1. 拉取官方仓库

```shell
https://github.com/ant-design/ant-design
```

2. 可以在本地新建一个分支，作为专门的笔记仓库。我的笔记仓库地址：https://github.com/Chiaki-xps/ant-design-source-code-note
3. 添加远程分支（这样做的目的是，一个仓库用来阅读源码，一个用来给官方提交PR）

- `origin` 远程仓库：用于同步官方最新代码，便于向官方提交 PR
- `chiaki` 远程仓库：用于保存个人学习笔记和代码注释

```shell
# 添加远程仓库
git remote add chiaki git@github.com:Chiaki-xps/ant-design-source-code-note.git

# 推送到 chiaki 远程仓库
git push chiaki master
```

## 3. 安装依赖并启动

```shell
# 安装依赖
pnpm install

# 启动开发服务器 访问 http://localhost:8001
pnpm start
```

### 🎯 项目特点

1. **组件化架构**: 每个组件都是独立的模块，包含完整的实现、文档、测试和样式
2. **TypeScript**: 全面使用 TypeScript 开发，提供完整的类型定义
3. **国际化支持**: 双语文档和国际化配置
4. **完善的测试**: 单元测试、集成测试、端到端测试全覆盖
5. **自动化工具**: 丰富的构建、发布、代码生成脚本
6. **多格式支持**: 支持 CommonJS、ES Module、UMD 等多种模块格式
7. **设计系统**: 完整的设计令牌系统和主题定制能力
8. **工程化**: 现代化的前端工程化实践，包括代码检查、自动化测试、CI/CD
